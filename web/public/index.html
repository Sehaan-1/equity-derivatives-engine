System Architecture & Low-Latency C++ Specifications

Lock-Free SPSC & MPSC Ring Buffer

Uses atomic memory orderings (acquire/release) without mutex locks or system calls. Head and tail pointers are aligned to separate 64-byte cache lines (alignas(64)) to prevent CPU L1/L2 cache line bouncing and false sharing.

Pre-Trade Risk Engine

Evaluates pre-trade safety controls inline and reports measured latency from each compiled simulator run. Features fat-finger order quantity limits, price collar percentage checks, order rate limiters, and daily drawdown circuit breaker.

Zero-Allocation Object Pool

Pre-allocates queue storage and OMS pools for Tick, OrderRequest, ActiveOrder, and ExecutionReport at engine boot for bounded hot-path memory use.
